# ProPresenterBibles


Форк оригинального репозитория ProPresenterBibles с добавлением большего количества русских переводов и инструкцией по конвертации других переводов в читаемый для ProPresenter формат.

Список доступных переводов на данный момент:

Windows: 
- Слово Жизни
- Перевод Кулакова (BTI)
- Современный перевод MDR
- Российское Библейское общество (РБО)
- Уточненный синодальный перевод (RSTI)
- Русский современный перевод (РСП)
- Новый русский перевод (NRT)

MacOS:
- Перевод Кулакова (BTI)
- Новый русский перевод (IBS)
- Современный перевод MDR
- Новый русский перевод (NRT)
- Российское Библейское общество (РБО)
- Русский современный перевод (РСП)
- Синодальный перевод (RST)
